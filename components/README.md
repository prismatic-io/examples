# Example Components

This directory contains example components for demonstration purposes.

- [GRPC Example](./grpc-example/) demonstrates how to connect to a gRPC service from a Prismatic component.
- [On Prem Example](./on-prem-example/) leverages Prismatic's [on-prem agent](https://prismatic.io/docs/integrations/connections/on-prem-agent/) to connect to a non-internet-facing web service.
- [Salesforce Field Mapping Example](./salesforce-field-mapping-example/) illustrates a [JSON Forms-based](https://prismatic.io/docs/integrations/data-sources/json-forms/) field mapper for Salesforce record fields.
- [SFTP Streaming](./sftp-streaming/) details how you can [stream large files](https://prismatic.io/docs/custom-connectors/handling-large-files-in-custom-components/) between systems using native Node.js buffers.

## Public components

The source code for all Prismatic-provided public components are available in the [prismatic-io/components](https://github.com/prismatic-io/components) repo.
