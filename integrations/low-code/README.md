# Low-Code Integration Examples

This directory contains examples that are referenced by [Prismatic Documentation](https://prismatic.io/docs).
To accelerate your low-code integration development, select **+ Add Integration** within the Prismatic web app, and then select **View Templates** under **Low-Code**.
Many templates are available that solve a variety of common integration scenarios.

| Example                                                       | Description                                                                                                       |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [dropbox](./dropbox/)                                         | A router integration that sends events from Dropbox's single webhook endpoint to the right customer's instance.   |
| [slack-interactivity-example](./slack-interactivity-example/) | An interactive Slack poll, plus a router integration that sends Slack interactivity events to the right instance. |
